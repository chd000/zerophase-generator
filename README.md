Генератор потоков для загрузки данных с ODS проекта ОВЮЛ

Подробное руководство: [РУКОВОДСТВО_ПОЛЬЗОВАТЕЛЯ.md](РУКОВОДСТВО_ПОЛЬЗОВАТЕЛЯ.md)

10.11.2026 (версия 1.1)
 -
 - Поддержка нового формата файлов описания: колонки «Таблица ODS_..._<команда>_SRC/_DLT/_TGT» вместо «Инкрементальная таблица»/«Таргетная таблица», шапка со строкой-группой Source/Target, атрибуты «Наименование атрибута» и «Тип AVRO»
 - В новом формате имя рабочего потока включает постфикс команды: `wf_ODS_<Схема>_<Таблица>_<команда>` (для старого формата правило прежнее); управляющий поток запускает рабочие потоки по обновлённым именам
 - Служебные поля ODS$*/DWH$*, перечисленные в листе атрибутов, больше не дублируют порты маппингов и колонки DDL
 - Строки, выделенные в Excel красной заливкой, не попадают в генерацию (ненужные таблицы и атрибуты); если красным отмечены все атрибуты таблицы — таблица пропускается целиком
 - В журнале работает выделение и копирование (Ctrl+C, правый клик); в диалоге Process ID вводится один начальный ID на таблицу — SRC = n, DLT = n+1, TGT = n+2
 - Исправлено чтение колонки описания таблиц (заголовок «Описание таблиц источника» не распознавался)
